# England North Volleyball website

The live site for England North Volleyball, hosted on Netlify.

- Programme cards, dates, prices and places live in the `CONFIG` block at the top of `app.js`.
- Page text and layout are in `index.html`. The privacy notice is `privacy.html`.
- Security headers are in `_headers`.
- Every change saved to the `main` branch publishes to the live site automatically.
